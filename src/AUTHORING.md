# 하나마루 일본어: 주차 학습지 작성 규칙

한 주차 파일(`src/wNN.js`)을 쓰는 사람이 따르는 규칙이다. 학습자는 한국인 성인, 완전 초보에서 시작했고 한자를 거의 모른다. 하루 30~60분, 85주 동안 JLPT N5 → N4 → N3 → N2 순서로 올라간다. 전체 주차 제목은 `src/roadmap.js`의 `weeks` 배열(0번이 1주차)에 있다.

## 시작하기 전에

1. `src/h.js`를 읽는다. 도우미 함수와 행 형식이 주석에 있다.
2. 완성된 주차를 본보기로 읽는다. N5·N4 단계는 `src/w04.js`, 그 이후도 구조와 말투는 같다.
3. `node tools/used.js NN`을 실행한다. 앞 주차에서 이미 쓰기 연습을 한 한자와 다룬 문형이 나온다. 같은 문형을 새것처럼 다시 가르치지 않고, 쓰기 한자는 아직 안 나온 글자에서 고른다. 병렬로 작성 중인 앞 주차는 목록에 없을 수 있으니, `roadmap.js`의 앞 주차 제목을 보고 이미 배웠다고 가정한다.
4. 자기 주차 파일 하나만 만든다. 다른 파일은 고치지 않는다.
5. 끝나면 빌드로 검증한다. 자기 주차에 대한 PROBLEMS 줄이 없어야 한다. 다른 주차의 문제는 무시한다.

## 파일 형식

```js
const { intro, tip, chars, write, vocab, grammar, dialog, listen, read, quiz, day } = require('./h.js');
module.exports = { title: 'roadmap.js의 그 주차 제목 그대로', days: [ /* day(...) 정확히 7개 */ ] };
```

- 행 구분자는 `|`이다. 내용 안에 `|`를 쓰지 않는다. 퀴즈 보기는 `/`로 나누므로 보기 안에 `/`를 쓰지 않는다.
- 일본어 안의 모든 한자에는 바로 뒤에 후리가나를 붙인다. `学生[がくせい]`, `食[た]べます`. 예외는 `write(...)`의 글자뿐이다. 설명문(한국어) 안에 일본어를 인용할 때도 마찬가지다. 빌드가 검사한다.
- 한자 읽기 문제처럼 후리가나를 일부러 숨겨야 할 때만 중괄호를 쓴다: `{学校}に 行[い]きます。`. 중괄호 안은 후리가나 검사를 건너뛰고 화면에 밑줄로 나온다. 퀴즈 문제 칸에서만 쓴다.
- N5·N4 단계의 일본어 문장은 어절 사이를 띄운다(`私[わたし]は パンを 食[た]べます。`). N3부터는 실제 일본어처럼 붙여 쓴다.
- 설명은 모두 한국어, 합니다체, 짧은 문장. 이모지는 `vocab`의 그림 필드에만 쓴다. `**굵게**`는 핵심에만 쓴다. 한국어 소리를 인용할 때는 “ ” 를 쓴다.
- `vocab` 행의 네 번째 칸은 그림 이모지다(`ねこ|고양이||🐱`, 메모가 없으면 세 번째 칸을 비운다). 뜻이 그림으로 바로 떠오르는 구체적인 단어에만 붙인다. 추상어에는 붙이지 않는다.
- `day(title, goal, steps, opt)`. `steps`는 핵심 학습(약 30~35분)이고 반드시 `quiz(...)`로 끝난다. `opt`는 시간이 더 있는 날의 보너스(약 15~20분, 1~2단계)다.
- 말하기 연습 단계는 앱이 그날의 문형 예문과 회화에서 자동으로 만든다. 따로 쓰지 않는다. 그래서 예문과 회화 줄은 소리 내어 말하기 좋은 길이(34자 이하)로 쓴다.
- 퀴즈 행: `문제|보기1/보기2/보기3|정답 번호(0부터)|해설|질문 문구`. 단어 뜻 문제는 앱이 `vocab`에서 자동으로 만들므로, 문형·조사·내용 이해 문제를 쓴다. 정답 위치를 골고루 섞는다.

## 내용 원칙 (학습자 후기 조사에서 나온 것)

- **하루 분량을 지킨다.** 포기 원인 1위가 과부하다. 단계별 상한은 아래 표를 따른다.
- **한국어에 기댄다.** 어순과 조사가 한국어와 거의 같다는 점을 쓰고, 다른 점만 짚는다.
- **한자는 단어 속에서, 한국 한자음과 연결해서.** 새 한자어는 메모 칸에 한국어 한자어와의 대응을 적는다(`会社[かいしゃ]|회사|한국어 “회사”와 같은 한자어. “회”가 かい, “사”가 しゃ입니다.`). 받침 ㄴ→ん, ㄱ→く·き, ㄹ→つ·ち, ㅂ→장음 같은 규칙을 기회 있을 때마다 상기시킨다. 훈독 단어는 한자의 뜻을 한국어 단어로 알려 준다(“한자는 ‘음료’의 ‘음’입니다”).
- **쓰기 한자**는 하루 2~3자(N3부터 3~4자), 그날 단어에 나온 글자로 `write('食飲見', '오늘의 한자 써보기')`. 한 글자짜리만 넣는다.
- **매일 회화나 청해 하나.** 4~6줄, 화자는 A와 B, 한 문장짜리 한국어 장면 설명. 주제는 여행·일상 상황, 그리고 애니·드라마에서 자주 들리는 일상 표현이다. 특정 작품을 인용하거나 이름을 대지 않는다.
- **7일째는 복습과 테스트만.** `tip` 요약 하나, 그 주의 문형을 다시 쓰는 `dialog`(또는 N3 이후 `read`) 하나, 10문항 `quiz`. 새 단어와 새 문형은 없다. `opt`는 `[]`.
- 일본어는 정확하고 자연스러운 표준어여야 한다. 그날까지 배운 문형만 쓴다. 읽기(특히 수사, 조수사, 음편, 연탁)와 활용형을 하나하나 확인한다.

## 단계별 하루 구성

| 단계 | 주차 | 하루 핵심 구성 | 상한 |
|---|---|---|---|
| N5 | 3~14 | 단어 → 문형 1~2개 → 회화 → 한자 쓰기 → 퀴즈 3~5문항 | 새 단어 8개, 문형 예문 3개씩 |
| N4 | 15~32 | 단어 → 문형 2개 → 회화(반말 회화를 점점 늘림) → 한자 쓰기 → 퀴즈 4~5문항 | 새 단어 9개, 예문 3개씩 |
| N3 | 33~55 | 단어(한자어 위주) → 문형 2개 → `read` 또는 `listen`(하루씩 번갈아) → 한자 쓰기 → JLPT 형식 퀴즈 5문항 | 새 단어 10개, 지문 150~250자 |
| N2 | 56~85 | 단어 → 문형 2개 → `read`(250~400자) 또는 `listen` → 한자 쓰기 → JLPT 형식 퀴즈 5~6문항 | 새 단어 10개 |

- N4부터 보통체(반말)와 활용형이 나온다. 활용 규칙은 표처럼 줄글로 정리하고(1그룹·2그룹·3그룹), 예외를 따로 적는다.
- N3·N2의 퀴즈는 실제 JLPT 문제 유형을 흉내 낸다: 한자 읽기, 문맥 규정, 유의 표현, 문장 만들기(빈칸), 지문 내용 이해. 지문 이해 문제는 그날 `read`·`listen` 내용에서 낸다.
- `read(title, [일본어 문단...], [한국어 해석 문단...])`: 문단 수를 맞춘다. `listen(title, 장면, [줄...])`: 형식은 `dialog`와 같고, 앱이 대본을 가린 채 먼저 들려준다.
- 제목에 “모의고사”나 “총정리”가 들어간 주차: 1~6일째는 영역별 미니 모의고사(하루에 `tip` 풀이 요령 하나 + `read` 또는 `listen` 하나 + 12~15문항 `quiz`)로 구성하고, 틀리기 쉬운 포인트를 해설에 적는다. 새 단어 단계는 넣지 않아도 된다.
- 제목에 “회화”나 “드라마”, “애니”가 들어간 주차는 `dialog`·`listen`을 하루 두 개로 늘리고 문형은 하나로 줄인다.
