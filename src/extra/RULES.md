# 보충 단어 작성 규칙 (src/extra/eNN.js)

본 학습지(src/wNN.js)의 단어만으로는 N2까지 약 3,100개라서, 매일 “보충 단어”를 더해 85주 누적 약 6,000개를 만든다. 보충 단어는 그날 학습 끝(확인 문제 바로 앞)에 “보충 단어” 단계로 나오고, 학습을 마치면 복습 카드로 쌓인다.

## 형식

```js
// NN주차 보충 단어 (주차 제목)
module.exports = { days: [
  [ '学校[がっこう]|학교|“학교”와 같은 한자어. “학”의 ㄱ 받침이 っ로 줄어듭니다.', '...' ],  // 1일째
  [ ... ], [ ... ], [ ... ], [ ... ], [ ... ],                                          // 2~6일째
  [],                                                                                   // 7일째는 비움 (복습일)
] };
```

- 한 행: `일본어|뜻|메모(선택)|그림 이모지(선택)` — 본 학습지 `vocab` 행과 같다. `|` 를 내용에 쓰지 않는다.
- 일본어의 모든 한자 바로 뒤에 후리가나: `食[た]べ物[もの]`. 메모 안에 일본어를 인용할 때도 같다. 빌드가 검사한다.
- 요일별 개수: N5(3~14주)·N4(15~32주)는 **하루 4개**, N3(33~55주)·N2(56~85주)는 **하루 7개**. 1~6일째만, 7일째는 `[]`.
- 메모는 짧게(한 문장). 한자어는 한국 한자음과의 대응(“‘학교’의 ‘학’”), 훈독어는 한자의 뜻을 한국어로. 메모가 필요 없으면 비운다.
- 그림 이모지는 뜻이 그림으로 바로 떠오르는 구체어에만.

## 단어 고르기

- 그 단계(N5/N4/N3/N2) 시험에 자주 나오는 수준의 단어. 특정 시판 단어장을 베끼지 말고, 자주 쓰는 단어를 스스로 고른다.
- 품사를 섞는다: 명사만이 아니라 동사(자동사·타동사 짝), 형용사, 부사, 가타카나어, 자주 쓰는 복합어.
- 가능하면 그 주차 제목이나 그날 주제와 이어지는 단어를 고른다. 무리하게 맞추지 않아도 된다.
- 동사는 사전형으로(N5 초반 3~6주는 ます형도 가능), 형용사는 기본형으로 적는다.
- 3~4주차(가나를 막 배운 단계)는 히라가나·가타카나만으로 된 쉬운 말 위주로.
- **이미 나온 단어와 겹치지 않게 한다.** `node tools/words.js --list` 로 지금까지 쓰인 단어를 보고, 다 쓴 뒤 `node tools/words.js NN` 으로 겹침을 확인해 바꾼다. 다른 사람이 동시에 다른 주차 보충 단어를 쓰고 있으니 끝나기 직전에 한 번 더 확인한다.
- 뜻은 가장 흔한 뜻 하나(필요하면 둘)를 한국어로. 정확해야 한다.

## 끝나면

`node tools/build.js "<kanjivg 경로>"` 로 빌드해 자기 주차 관련 PROBLEMS 줄이 없는지 확인한다.
